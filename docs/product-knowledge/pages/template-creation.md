# Template Creation Wizard

## 1. What is this page?
The Template Creation Wizard is the interactive design interface (embedded within the WhatsApp Templates dashboard) used to construct, lint, preview, and submit new message templates to Meta for approval.

## 2. Why is this page useful?
WhatsApp has rigid formatting rules and policy constraints for templates.
- **Why do users need it?** To build rich-media message templates (with variables, headers, and interactive buttons) that are guaranteed to comply with Meta's policies.
- **What work does it make easier?** It offers an instant visual simulator on the right side of the screen that updates as you type, and features a built-in compliance checker (linter) to prevent rejections.
- **What business process does it support?** Outbound Messaging Configuration, Campaign Preparation, and Compliance Management.
- **What happens without it?** Users would submit templates blindly, resulting in high rejection rates from Meta due to formatting errors or category policy mismatches (e.g. putting promo text in utility templates).

## 3. Who uses this page?
| Role | Why they use it |
|---|---|
| Marketing Manager | To write message copy, select languages, map dynamic variable placeholders, upload header media, and add quick action buttons. |
| Admin | To audit compliance warnings and submit templates to Meta for approval. |

## 4. What can users do here?
- **Configure Core Info:**
  - Define the template Name (lowercase, numbers, and underscores only).
  - Select Category: **Marketing** (offers, promos), **Utility** (receipts, transactions), or **Authentication** (OTPs).
  - Select from over 70 Languages.
- **Design Message Layout:**
  - Set Header Type: **None**, **Text** (supports header variables), or **Media** (Image, Video, Document). Upload files up to 10MB to generate Meta media handles.
  - Write the Message Body with rich-text toolbar controls (Bold, Italic, Strikethrough, and Emojis).
  - Add dynamic variable placeholders (e.g., `{{1}}`, `{{2}}`).
  - Add footer text (e.g. opt-out instructions).
- **Configure Interactive Buttons (Quick Actions):**
  - Add **Quick Reply** buttons (up to 3).
  - Add **Call-to-Action** buttons (URLs, Phone Numbers, or Copy OTP Code).
- **Test & Preview:**
  - View a real-time visual simulation of the WhatsApp chat bubble.
  - Fill in sample values for variables to see how they render in the preview.
- **Review Compliance Audits:**
  - View warning warnings generated by the pre-submission linter.
  - Decide to go back and fix issues or override and submit anyway.

## 5. What is involved?
- **Meta Upload API:** Handles uploading media assets (images, PDFs) directly to Meta's servers to generate binary header handles.
- **TemplateValidator:** Runs local regex and dictionary scans on the template text to check for compliance risks.
- **WhatsAppService:** Pushes the finalized template payload structure (components, variables, headers, buttons) to Meta's Business API.

## 6. How does it work?
1. The user opens the creation modal. They name the template `billing_receipt_v1` and select category "Utility".
2. They upload a PDF template invoice as a "Document" header.
3. They write the body text: "Hi {{1}}, your invoice for {{2}} is ready."
4. The system detects two variables. The user maps sample text: `{{1}}` &rarr; "Alice", `{{2}}` &rarr; "$50".
5. The right-hand preview panel instantly shows a bubble with the PDF icon and the parsed greeting.
6. The user clicks "Submit". The validator analyzes the text. If it detects promotional language like "Get 10% off on your next purchase", it displays a Compliance Warning blocking submission.
7. The user removes the promo text, clicks submit again, and the payload is successfully sent to Meta.

## 7. What happens behind the scenes?
- **Media Upload Tokenization:** When a media file (Image, Video, or Document) is uploaded in the header, the file is pushed to Meta's Resumable Upload API. Meta returns an upload handle token (e.g., `header_handle: "XYZ123"`). This handle is embedded in the template creation payload so Meta can verify and approve the media layout.
- **Compliance Rules Engine:** The `TemplateValidator` scans the components:
  - **Category Audit:** Checks if a template marked as "Utility" contains prohibited marketing words (like "deal", "coupon", "save", "offer").
  - **Variable Formatting:** Checks that variables are sequential (e.g., `{{1}}`, `{{2}}`, not `{{1}}`, `{{3}}`) and that sample data is provided for every placeholder.
  - **Button Constraints:** Enforces that Quick Reply buttons and CTA buttons are never mixed in the same template (Meta rejection rule).
- **Authentication Safeguards:** If "Authentication" category is selected, the body text is locked to Meta's strict verification template, and the buttons are automatically restricted to OTP/Copy Code types.

## 8. Business Use Cases

**Use Case 1: Submitting a Rich Media Promo**
- **Situation:** A marketing team wants to send a video guide of a new product to their leads.
- **How the feature is used:** They create a "Marketing" template, set the header to "Video", upload the video MP4 file, add a CTA link button labeled "Buy Now", and submit.
- **Customer experience:** Leads receive an engaging message with an embedded video player and a quick checkout button.
- **Business outcome:** High click-through rates.

**Use Case 2: Standardizing Transaction Reciepts**
- **Situation:** An e-commerce brand needs to send PDF receipts automatically when a purchase is made.
- **How the feature is used:** They create a "Utility" template with a "Document" header and a body variables mapping the customer's name and order ID.
- **Customer experience:** The customer receives a message with their PDF invoice attached.
- **Business outcome:** Streamlined, automated transaction alerts.

**Use Case 3: Creating Verification Codes**
- **Situation:** A bank needs to deliver OTP codes to customers logging into their portal.
- **How the feature is used:** They select category "Authentication". The body text automatically sets to a secure template, and a "Copy Code" button is added.
- **Customer experience:** The user receives a message, taps "Copy Code", and pastes it into the login screen.
- **Business outcome:** Frictionless security flows.

## 16. Important Rules
- Names cannot contain uppercase letters or spaces (use lowercase and underscores, e.g. `order_alert`).
- Senders cannot mix Quick Reply and CTA buttons.
- Header uploads are limited to 10MB.

## 17. Common Problems
- **Problem:** Linter shows compliance warnings and won't let me submit.
  - **Possible reason:** You selected "Utility" but your text contains marketing/sales words, or you didn't fill in sample variables.
  - **What the user should do:** Review the warning log. Remove promotional phrases from utility templates, or switch the category to "Marketing". Ensure all variable inputs have sample values.
- **Problem:** Media upload fails.
  - **Possible reason:** The file exceeds 10MB, or is in an unsupported format (e.g. webp instead of jpeg, or webm instead of mp4).
  - **What the user should do:** Convert the image to JPEG/PNG or video to MP4, resize it to under 10MB, and try uploading again.

## 18. Simple Explanation for Sales

## 20. Simple Explanation for Support
If you need a new template to reply to customers after the 24-hour window, you must design and submit it here first. Once Meta approves it, it will appear in your inbox options.
